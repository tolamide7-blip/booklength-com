How to Measure Book Cover Spine for Print: Bleed, Wrap, and Template

Full cover wrap = (Width×2)+Spine+0.25 bleed. Template size, KDP upload guide - gets backlinks from designers. • Built in Austin, Texas, USA

Full Cover Wrap Formula (Designers Bookmark This)

Total Width = (Trim Width ×2) + Spine Width + 0.25" bleed (0.125" each side)

Total Height = Trim Height + 0.25" bleed

Example 6x9", 250pp White: (6×2)+0.563+0.25 = 12.813" wide × 9.25" tall

KDP Upload Checklist

  • PDF, 300 DPI
  • Include 0.125" bleed on all sides
  • Spine text centered, keep 0.0625" from spine edge
  • Export as PDF/X-1a
